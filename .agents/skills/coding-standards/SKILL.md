name: coding-standards
description: Defines and enforces coding standards for the project. Use when working with code reviews or implementing new features.
---

コーディングする際は以下の点に注意して書くこと。

- 初見で読んだ人が理解する時間が最小限になるように、可読性を意識して書くこと。
- 具体的には、以下の点に注意すること。
  - 変数名、関数名は意味のある名前をつけること。
  - コメントは必要最低限にすること。コードから意図が読み取れる場合はコメントを省略すること。
  - コードの構造はシンプルにすること。複雑な処理は関数に切り出すこと。
  - コードの重複は避けること。共通処理は関数に切り出すこと。
